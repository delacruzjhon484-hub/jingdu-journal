# 精读手账馆 1.0

半知精读 Skill × 石雄带领的半知精读教研团队。

本仓库是精读手账馆的公开 GitHub Pages 版本，`docs/` 为已构建的静态网站。保留动态手账工坊、精读手账试读、场景白板、陪学营介绍和半知社区入口。

- 阅读笔记、进度、自建清单与学习计划仅保存在当前浏览器，不会提交给网站或跨设备同步。
- 社区名片、社区展示和 PDF 投稿通过页面入口前往在线版，需要在线版访问权限。
- 不包含在线版数据库、会员资料、投稿文件或服务器凭据。

## 本地运行与更新

需要 Node.js 22.13 或更高版本。

```sh
npm install
npm run dev
```

更新后执行 `npm run build`，将源文件与 `docs/` 一起提交。GitHub Pages 的发布源设为 `main` 分支的 `/docs` 目录。
